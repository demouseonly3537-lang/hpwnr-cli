# hpwnr

Command-line version of [Happwner](https://github.com/Omegaplexx/Happwner). A **Happ** and **v2RayTun** subscription-link decryptor/encryptor that can fetch, decrypt, encrypt, and convert proxy profiles. It is available as both a CLI tool and a Rust library.

Developed by slavrom21 & Omegaplex

Full source and docs: https://github.com/Omegaplexx/hpwnr

This mirror includes the CI workflows for multi-platform builds (Linux, Windows, macOS, iOS, Android binaries).

## Quick build

```bash
cargo build --release
```

Android binaries are produced by the GitHub Actions workflows in `.github/workflows/`.
